# LithoCreate Pro

Eigenständig nutzbares, deutsches Windows-Lithophaniestudio in C# / .NET 10 / WPF. Bildbearbeitung, Geometrie, Rendering, Projekte und Exporte laufen lokal. Die Oberfläche orientiert sich an den beiden mitgelieferten Designreferenzen.

## Starten

- [Windows-Downloads auf GitHub](https://github.com/hahawasistlos1/LithoCreate-Pro/releases/latest)
- **Setup per Doppelklick:** `artifacts/LithoCreate-Pro-1.22.0-Setup.exe`
- **Installer als MSI:** `artifacts/LithoCreate-Pro-1.22.0-win-x64.msi`
- **Portable Anwendung:** `artifacts/portable-1.22.0/LithoCreate Pro.exe` (den gesamten Ordner zusammen behalten).
- **Visual Studio:** `LithoCreatePro.sln` mit Visual Studio 2026 und .NET-Desktopentwicklung öffnen.

Die veröffentlichte Anwendung enthält .NET 10 für Windows x64. Auf dem Zielrechner sind weder SDK noch separat installierte .NET-Laufzeit erforderlich. Mindestziel: Windows 10/11 x64. Das Paket ist nicht digital signiert.

Version **1.20.0** ergänzt STL-Prüfung, separat ausgeführte Formmodule, LED-/E14-/E27-Maßhalterungen, Montageplatten mit freien Bohrungen, PETG-Probedrucke und die lokale Übergabe an Bambu Studio. P1S/PETG kann als Profil hinzugefügt werden. Projektformat 15 bleibt mit Version 1.18/1.19 kompatibel. Abnahme und verbleibende praktische Voraussetzungen stehen in docs/ABARBEITUNG.md.

## Entwicklung

```powershell
./build.ps1
```

Das Skript baut die Lösung, führt die ausführbaren Integrationstests aus, veröffentlicht die eigenständige Windows-Anwendung und erzeugt das native MSI. Ein erstmaliger Self-contained-Build lädt offizielle .NET-Laufzeitpakete von NuGet; die fertige Anwendung benötigt keine Verbindung. Zum Offline-Bauen müssen diese Pakete bereits im lokalen NuGet-Cache liegen.

Die Anwendung bietet den vollständigen lokalen Ablauf vom Foto zur geprüften Modelldatei. Noch nicht erfüllte Teile des Gesamtauftrags werden ausdrücklich im Funktionsumfang geführt; ein vollständiger Drucktest und eine Freigabe für jede Hardwarekonfiguration werden nicht behauptet.
